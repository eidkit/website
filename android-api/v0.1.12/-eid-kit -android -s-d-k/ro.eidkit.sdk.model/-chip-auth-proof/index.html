ChipAuthProof

data class ChipAuthProof(val terminalPublicKey: ByteArray, val ephemeralPrivateKey: ByteArray, val sharedSecretX: ByteArray, val rawDg14: ByteArray)

Cryptographic proof from BSI TR-03110 Chip Authentication, carried inside a CeiIdentityClaim.

CA proves the physical chip holds the private key corresponding to the public key in DG14, which is hashed in the SOD by MAI. This binds the identity data (DG1) and the CE81 active authentication key to the same physical card via a single MAI-signed document (EF.SOD).

The server recomputes sharedSecretX = ECDH(ephemeralPrivateKey, Q_chip_from_DG14) and verifies it matches — proving the phone interacted with the chip that holds the DG14 key.

ephemeralPrivateKey is a single-use scalar generated fresh per session. It has no value beyond this session and is safe to transmit to your own verification server.
